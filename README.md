Leonida Platinum Atlas — all 55 Grand Theft Auto VI trophies, each with a guide in our own words that names its sources, an 8-stage roadmap to platinum, the one trophy you can miss flagged up front, and a spoiler-safe offline tracker with saved progress, kind and grade filters, export and import. Static files, no build step, works with the network off.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — or open `app/index.html` directly in desktop Chrome. To hand the entry in, run `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`.
