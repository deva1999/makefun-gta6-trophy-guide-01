Leonida Platinum Fieldbook — an offline tracker and cited guide for all 55 Grand Theft Auto VI trophies on PlayStation 5. Every trophy carries its official name, description and grade, a guide written in our own words that names its sources, a missable flag, and a place in an 8-stage roadmap to the platinum. Progress saves in the browser, with kind and grade filters, a spoiler setting that hides the 28 hidden story trophies until they are earned, and export / import. No network requests, no Rockstar artwork — plain static files that open in desktop Chrome with the network off.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080
