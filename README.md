An offline guide and tracker for all 55 Grand Theft Auto VI trophies on PlayStation 5 — every trophy with its official name, description and grade, a guide in our own words with a named source beside every fact, an 8-stage roadmap to platinum, the one potentially missable trophy flagged, and a spoiler-safe checklist that saves progress in the browser.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. No build step, no network requests — the app is static files under `app/`.

To hand it in locally:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
